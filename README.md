# Colina Financial Management

Personal finance app built with Expo and React Native, backed by a Node.js API with Prisma and PostgreSQL.

## Structure

| Folder                  | Content                         |
| ----------------------- | ------------------------------- |
| `gestao-financeira`     | Mobile app (Expo, React Native) |
| `gestao-financeira-api` | REST API (Node.js, Prisma)      |

## Getting Started

**API**

    cd gestao-financeira-api
    npm install
    npm start

**App**

    cd gestao-financeira
    npm install
    npx expo start

## Tech Stack

Expo · React Native · JavaScript · Node.js · Prisma · PostgreSQL
